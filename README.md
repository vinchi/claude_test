# Dino Runner 🦖

크롬에서 인터넷이 끊겼을 때 나오는 공룡 게임을 따라 만든 버전입니다. 외부 의존성 없이 `index.html` 파일 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 로컬 서버로 띄우려면:

```bash
npx serve .
```

## 조작

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 시작 / 점프 | `Space`, `↑`, `W` (길게 누르면 더 높이) | 화면 탭 |
| 숙이기 / 빠른 낙하 | `↓`, `S` | 아래로 스와이프 |
| 재시작 | `Space`, `Enter` | 화면 탭 |
| 소리 끄기/켜기 | `M` | - |

## 기능

- 점프 / 숙이기 / 공중에서 빠른 낙하
- 크기와 개수가 다른 선인장, 300점 이후 등장하는 익룡 (낮음·중간·높음)
- 점점 빨라지는 속도, 100점마다 효과음과 점수 깜빡임
- 700점마다 밤 모드 전환
- 최고 점수 저장 (localStorage)
- Web Audio 효과음, 고해상도(Retina) 화면 대응
- 네트워크 상태 표시 (오프라인이면 "인터넷에 연결되어 있지 않음")
